# lac3 Homebrew tap

```bash
brew tap lac3/tap
brew trust lac3/tap
brew install gpg-gui
ln -sf "$(brew --prefix gpg-gui)/GPG GUI.app" /Applications/
```

| Formula | Description |
|---|---|
| `gpg-gui` | Simple graphical interface for GPG file encryption and decryption ([source](https://github.com/lac3/gpg_gui)) |
